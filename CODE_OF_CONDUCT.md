# Code of Conduct

Short version: be decent.

This is a free tool with one maintainer. Issues, PRs, and discussions should be
somewhere you'd be comfortable being read by a stranger — because they will be.

**Expected:** patience, good faith, and the assumption that the person on the
other end is doing their best with limited time.

**Not welcome:** harassment, personal attacks, demeaning comments about anyone's
identity or skill level, or treating a free project like a paid support desk.

Reports go to the maintainer via a
[private security advisory](https://github.com/elixir-bash/inboxsweeper/security/advisories/new)
(it's the only private channel this repo has). I'll read it. Consequences run
from a warning to a block, at my discretion — and that's the whole process.
There's no committee here.
